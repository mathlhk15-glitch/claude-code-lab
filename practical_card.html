Claude Code 핵심 11 실전 요약 카드

처음 한 번 Git을 준비하고, 이후에는 같은 안전 흐름을 반복합니다.
처음 한 번: Git 저장소 준비 → 이후 매번: /plan → 수정 → git status → git diff → 테스트 → git commit
1시작과 규칙
/init + CLAUDE.md
새 프로젝트를 Claude Code로 관리할 때 프로젝트 목적, 수정 금지 범위, 개인정보·배포 규칙을 먼저 정합니다.
기억할 말: 처음 시작할 때 규칙부터.
2작업 계획
/plan
중요한 수정 전에는 바로 고치지 말고, 읽을 파일·바꿀 파일·영향·테스트를 먼저 확인합니다.
기억할 말: 공사 전에 설계도.
3Git 저장소 준비와 변경 확인
처음 한 번
git status # 저장소인지 확인
git init # 아니라면 저장소 만들기
.gitignore # 제외할 파일 정하기
git add 필요한파일
git commit -m "첫 기준 저장"
이후 매번: git status로 어디가 바뀌었는지, git diff로 어떻게 바뀌었는지 봅니다.
기억할 말: 처음엔 Git 준비, 이후엔 status·diff.
4좋은 상태 저장
git commit
수정이 괜찮고 테스트도 통과했다면 필요한 파일만 add한 뒤 기준점으로 저장합니다.
기억할 말: 괜찮으면 저장점 만들기.
5되돌리기와 복구
Esc · /rewind · Git
작업이 이상하면 먼저 Esc로 멈춥니다. 최근 Claude 편집은 /rewind 또는 Esc 두 번. 오래된 변경과 터미널 삭제·이동은 Git 복구를 우선 봅니다.
기억할 말: 방금은 Rewind, 오래된 것은 Git.
6컨텍스트·토큰 관리
/context · /compact · /clear
/context는 현재 상황 확인, /compact는 긴 대화 압축, /clear는 완전히 새 작업 시작입니다.
기억할 말: 확인 · 압축 · 새로.
7어제 하던 작업 이어가기
/resume
매일 조금씩 공부하거나 작업할 때 이전 세션을 이어갑니다. 목적이 완전히 달라졌다면 새 세션이 낫습니다.
기억할 말: 어제 하던 일 다시 이어가기.
8권한·범위 통제
Plan Mode · Shift+Tab
작업 범위를 먼저 좁히고, 중요한 수정은 Plan Mode에서 계획을 확인합니다. 삭제·배포·외부 전송은 특히 조심합니다.
기억할 말: 편리함보다 안전.
9멈추기·도움말
Esc · Shift+Tab · /help
Esc는 즉시 중단, Shift+Tab은 권한 모드 전환, /help는 현재 버전에서 쓸 수 있는 명령과 단축키 확인입니다.
기억할 말: 멈추기 · 바꾸기 · 찾아보기.
10수정 후 최소 테스트
직접 실행 · 확인
완료 보고만 믿지 말고 브라우저 콘솔 오류, 핵심 버튼, 모바일 폭, 새로고침, 저장, 인쇄를 직접 확인합니다.
기억할 말: 수정 후에는 꼭 테스트.
11개인정보·Secret 경계
.gitignore · 공개 금지
학생 실명·학번·성적, 비밀번호, API Key, Token은 공개 HTML·JavaScript에 넣지 않습니다. 참고자료와 내부판은 .gitignore 등으로 분리합니다.
기억할 말: 올리면 모두가 본다.
!막히면 이렇게
1. Esc먼저 작업을 멈춥니다.
2. git diff실제 변경을 확인합니다.
3. /help 또는 기술 사전모르면 찾아보고 범위를 더 좁혀 다시 지시합니다.
같은 실패가 반복되면 계속 고치지 말고 원인을 먼저 확인.

처음 한 번: Git 저장소 시작하기

git status→git init→.gitignore→첫 commit

매번 반복하는 작업 흐름

/plan→수정→status→diff→test→commit
핵심 암기: 처음엔 Git 준비 / 매번은 /plan → 수정 → status → diff → test → commit
