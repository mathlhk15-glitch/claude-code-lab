0. 실전 요약 카드 + 책상용 카드

화면에서는 자세한 실전 요약 카드를 보고, 인쇄할 때는 작은 책상용 요약 카드를 엽니다. 두 카드 모두 “처음 한 번 Git 저장소 준비 → 이후 매번 /plan → 수정 → status → diff → test → commit” 흐름을 사용합니다.

먼저 외우면 좋은 흐름

처음 한 번과 매번 하는 일을 구분하세요

처음 한 번

git status → 필요하면 git init → .gitignore → 필요한 파일 add → 첫 commit

매번

/plan → 수정 → git status → git diff → test → git commit

막히면

Esc로 멈춤 → git diff로 실제 변경 확인 → /help·기술 사전
