Claude Code 핵심 11 책상용 요약 카드

모니터 옆에 붙여 두는 실전 치트시트 · 처음 Git 준비 → 매번 /plan → 수정 → status → diff → test → commit
처음 한 번: Git 저장소 준비
git status → 저장소가 아니면 git init → .gitignore 확인 → 필요한 파일 add → git commit -m "첫 기준 저장"
① 시작과 계획
1
/init + CLAUDE.md
새 프로젝트 시작. 오래 지킬 규칙부터 적기.
2
/plan
중요한 수정 전, 먼저 계획·범위·테스트 확인.
3
Git 준비 + status/diff
처음엔 Git 저장소와 첫 기준점 준비. 이후 status=어디가 바뀜, diff=어떻게 바뀜.
4
git commit
테스트가 괜찮으면 좋은 상태를 저장점으로 남기기.
② 되돌리기와 이어가기
5
Esc · Rewind · Git
Esc=즉시 중단 · Rewind=최근 Claude 편집 · 오래된 변경/터미널 삭제·이동=Git 복구.
6
/context · /compact · /clear
context=확인 · compact=압축 · clear=완전히 새 작업.
7
/resume
어제 하던 작업 이어가기.
③ 안전하게 작업하기
8
권한·범위 통제
작업 범위를 먼저 좁히고 중요한 변경은 Plan Mode에서 확인.
9
Esc · Shift+Tab · /help
Esc=멈춤 · Shift+Tab=권한 모드 전환 · /help=현재 버전 도움말.
10
최소 테스트
완료 보고 ≠ 테스트 통과. 수정 후 콘솔·핵심 기능·모바일·저장·인쇄 확인.
11
개인정보·Secret
학생 정보·비밀번호·API Key·Token 공개 금지. .gitignore 활용.

1 Esc로 멈추기→2 git diff로 실제 변경 확인→3 /help·기술 사전에서 찾기
